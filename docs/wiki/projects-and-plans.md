# Projects and plans

A project groups plans by a normalised folder path (usually the working directory the agent used). You can rename the display name; the path stays fixed.

A plan is a titled sequence of revisions. Each revision is an immutable Markdown snapshot. Archive a plan when the work is done so it leaves the active lists; restore it if you need it back. Delete removes the plan and its reviews.

While a plan is archived, new revisions from the agent do not land on it. Restore the plan first, or start a fresh one, if you want more rounds.
