# Dashboard

The dashboard is the start page. Above the metrics, a pending list shows every plan in an active project whose newest revision still has a pending review (oldest first). The title opens that review.

Headline numbers cover active projects only: approval rate, first-pass approval, median time to decision (last 30 days), median annotations on change requests, and plans plus revisions created in the last 30 days. The project table lists every project, archived last. Agent and model tables also count active projects only.

Project pages keep their own tabs (Pending, Changes requested, Recently approved, Archived). Those lists show a plan once, by the newest revision's review.
