# Decision fences

A decision fence is a question embedded in the plan as a Markdown `decision` code block. On the review page each one shows as a card.

Answer opens a dialog for that question. Choice fences list options; text fences take a free answer. Each question id appears once in the plan.

Answers stay with the review. Approve stays disabled while the plan has decision fences. Request changes can go ahead; unanswered questions show as `(unanswered)` in the feedback.
