# Decision fences

A decision fence is a Markdown code fence with language `decision`. It asks one question inside the plan. Call `get_plan_markdown_guide` before you write one if you need the exact shape.

On the review page, each fence shows as a card. Answer opens a dialog for that question. Choice fences list options; text fences take a free answer. Each `id` appears once in the plan.

Answers sit with the review. Finish answering before you approve or request changes if the agent needs those choices in the next revision.
