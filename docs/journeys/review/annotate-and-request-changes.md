# Annotate and request changes

As a reviewer, I mark what should change on a pending Revision and send that Feedback to the agent.

## Steps

1. Select text in the plan document.
2. Choose deletion, replacement, insertion, or comment from the selection popup.
3. Edit drafts as needed; they persist while the Review stays pending.
4. Request changes so the drafts become Feedback.
