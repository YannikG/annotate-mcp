# Enlarge a diagram

As a reviewer, I open a Mermaid diagram larger than the column so I can read it.

## Steps

1. Open a plan, document, revision, or review that contains a mermaid fence.
2. Choose Enlarge on the diagram.
3. Zoom in until a label is readable, drag to the part you need, then Recenter to see the whole diagram.
4. Close with Close, Escape, or the backdrop. The diagram is back in the column.
